# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report them privately via [GitHub's private vulnerability reporting](../../security/advisories/new).
If that is not available to you, send me a direct message on
[LinkedIn](https://www.linkedin.com/in/pkhabazi/) and I will open a private channel.

Include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept if applicable.
- The version of the module you are using.

You can expect an acknowledgement within **5 business days** and a resolution or mitigation
plan within **30 days** for confirmed issues, depending on severity.
